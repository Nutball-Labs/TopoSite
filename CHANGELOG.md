# Changelog

## Unreleased

- TopoSite logo: README header (light/dark), browser-tab icon
- Node names layer: show or hide node name labels (previously they appeared
  only when zoomed in); saved per map

## 0.2.0 — 2026-10-10 (first public release)

- Maps: several saved maps, each with its own background (light + optional
  dark version), node positions, node list (include all / exclude all +
  exceptions) and saved view; a default map opens on load
- Built-in Network Graph map with a force-directed layout
- Edit mode: show/hide nodes with quick selects, unplaced tray, drag to place
- Hidden repeaters on shown routes drawn as ghosts
- Mesh health: isolated / few-neighbor / backup-route / weak-signal flags,
  weak-hop badges, one-way neighbor lines, pane list
- Battery level layer with low-battery highlighting
- Export / import of a map (`.toposite`) with reviewed device matching and
  placeholders
- Refresh neighbors button (Z-Wave JS UI's own API)
- Follows Z-Wave JS UI's theme and login

## 0.1.0 — 2026-10-06

- Plugin skeleton and `/toposite/api/nodes`
